# 플레이 목표와 시간 배분

성장 단계에 더해 적용하는 지침이다. 각 단계의 사용자가 여러 목표를 동시에 가질 수 있다. 커뮤니티에서 많이 보이는 방식보다 사용자가 직접 말한 선호를 우선한다. MCP topic은 `playstyle`다.

## 시간과 예산을 계획의 실제 조건으로 쓰기

하루/주 사용 가능 시간, 집중 사냥 가능 여부, 주말 보스 일정, 현재 즐기는 콘텐츠를 확인한다. 소요 시간은 알려진 실측·사용자 경험을 사용하고 콘텐츠 시간을 만들어내지 않는다. 정확하지 않으면 범위나 측정할 항목을 남긴다. 현재 루틴이 시간 한도를 넘으면 우선순위를 줄인 후 새 활동을 넣는다.

이번에 쓸 메소·추가 지출 의향·재료·이벤트 보상을 구분한다. 무료 재료도 다른 캐릭터/부위에 쓸 기회비용과 만료일이 있다. 유료 패스·MVP·PC방·편의 아이템은 사용자가 이미 보유했거나 구매를 검토할 때 조건을 확인해 비교한다. 지불 의향이 없으면 그 조건을 제외한 계획을 만든다.

## 목표별 적용

| 플레이 목표 | 비교할 성과 | 권할 행동과 제약 |
| --- | --- | --- |
| 짧은 접속·일퀘 중심 | 제한 시간 내 누적 성장, 피로도, 유지 가능성 | 현재 접근 가능한 핵심 성장 활동과 만료 보상을 추리고 남는 시간의 선택 활동을 분리; 매일 장시간 사냥이나 모든 부캐 숙제를 요구하지 않음 |
| 레벨·새 지역·사냥 편의 | 경험치/시간, 처치 횟수, 포스·레벨 조건, 이동/회수 피로도 | 같은 버프·시간의 짧은 실측을 비교; 접근 불가 지역을 추천하지 않고 보스딜 세팅과 사냥 세팅을 분리 |
| 솔로 보스·주간 안정화 | 실제 클리어/생존·목표 난이도·반복 부담 | 딜·패턴·유틸·프리셋 병목을 나누고 연습 가능 시간을 고려; 숙련자 최소컷을 여유컷으로 쓰지 않음 |
| 친구·파티 보스 | 함께 정한 목표, 인원·역할·시간, 파티 생존과 타이밍 | 실제 구성·역할과 모집 조건을 확인; 솔플 지표를 파티에 그대로 적용하거나 없는 시너지를 가정하지 않음 |
| 사냥 수익·드메 | 추가 순메소/시간, 초기 비용, 처치/회수 변화, 이용 기간 | 수익 장비·펫의 추가 이익을 현재 세팅과 비교; 기존 총수익을 투자 효과로 계산하지 않고 무조건 필수로 권하지 않음 |
| 부캐·주보·계정 성장 | 계정 효과 또는 수익, 추가 세팅비와 주간 시간, 본캐 지연 | 목적과 주차 지점을 정하고 실제 유지할 수 있는 캐릭터 수를 검토; 계정 전체 조회는 질문에 필요할 때만 함 |
| 복귀·시즌/버닝 육성 | 바뀐 규칙에 적응, 보상 사용과 시즌 후 유지 | 현재 월드·이벤트 적용 조건·받은 보상·기간제 만료·이동 규칙을 확인; 지난 시즌 일정과 지급품을 복사하지 않음 |
| 코디·수집·친목 | 사용자의 취향, 원하는 콘텐츠 접근, 소비 한도 | 현재 스펙 유지도 목표 달성일 수 있음; 보스·사냥의 수치 최적화를 목표 대신 넣지 않음 |

## 사냥 수익 투자 질문

가능하면 같은 지역·처치량·드롭/메획·버프·회수 방식에서의 전후 실측을 받는다. 수익은 메소 획득과 판매 재료를 구분하고 소모품·거래 비용을 반영한다. 확률 드롭과 시세는 가정 및 변동을 밝힌다. 원킬이나 회수 동선이 바뀌면 기존 시간당 수익을 그대로 유지하지 않는다.

입력이 충분할 때만 `추가 순투자비 / 추가 순수익(시간당)`으로 회수에 필요한 **플레이 시간**을 설명한다. 추가 순수익이 0 이하이면 유한한 회수 시간을 제시하지 않는다. 주당 실제 사냥 시간이 있을 때만 기간으로 바꾸며 가격·드롭이 일정하다는 가정을 밝힌다. 게임 내 재화 회수와 현실의 현금 수익을 합치지 않는다. 미확인 매물이나 극단적으로 좋은 수익 사례를 기본값으로 삼지 않는다.

## 여러 목표가 충돌할 때

사냥용 편의와 다음 보스 투자처럼 다른 성과를 최종뎀 한 숫자로 합치지 않는다. 두 계획의 효과·비용·시간을 나란히 설명하고 사용자가 어느 목표를 우선할지 선택하게 한다. 유니온·HEXA 등을 최대치까지 채우는 계획은 사용자가 그 목표를 원하고 비용/시간이 맞을 때 제안한다.

계획의 실행 부담이 크거나 사용자가 피로를 말하면 접속 시간 내 가능한 범위로 축소한다. 놓쳐도 되는 활동과 현재 목표에 가까운 활동을 구분하고, 휴식·주차·목표 변경을 실패로 표현하지 않는다.
