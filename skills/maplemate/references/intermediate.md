# 중급: 안정화와 목표 전환

현재 콘텐츠를 반복할 기반이 있고 다음 목표에 대한 자원 배분을 고민하는 캐릭터에 적용한다. 설명 난이도는 [성장 진단](progression.md)의 이해도에 맞춘다. MCP topic은 `intermediate`다.

## 안정화: 현재 플레이를 편하게 유지하기

현재 안정적으로 하는 보스/지역과 도전 중인 콘텐츠를 구분한다. 가능하면 클리어 시간·실패 패턴·생존·주간 반복 부담을 사용자에게 확인한다. API 장비가 좋은데 클리어가 불안정하면 코어·프리셋·직업 운영·포스·파티 조건을 먼저 대조한다. 주간 수익·클리어 이력을 자동 조회했다고 말하지 않는다.

세트·잠재·스타포스·코어·심볼·계정 기반 중 목표에 약한 항목을 찾는다. 한 부위의 성능 자체보다 **그 부위를 바꿀 때 생기는 증가분과 순투자비**를 비교한다. 인기 세팅의 착용 비율은 후보 발견에만 사용한다. 이미 비싸게 산 비용을 다시 써야 할 근거로 삼지 않는다.

주차를 원하면 그 콘텐츠를 편하게 반복할 정도에서 멈추는 계획을 허용한다. 상위 세트로 미리 넘어가는 비용, 매물 유동성·교환 조건, 나중에 다시 바꿀 비용을 대조한다. 현재 만족도와 플레이 시간이 충분하면 기다리기·유지도 투자 대안이다.

## 목표 전환: 다음 보스·지역·해방·세트

1. **다음 목표를 구체화한다.** 보스 이름뿐 아니라 난이도·인원·직업 역할·목표 기간을 확인한다. 해방이면 어떤 무기/퀘스트의 어느 단계인지 묻고 오래된 해방 기간을 현재 규칙으로 사용하지 않는다.
2. **부족한 요건을 분리한다.** 입장/레벨/포스·지속 딜·극딜·생존·조작·파티 조율·주간 재료 누적을 나눈다. 목표까지 필요한 주 수는 현재 규칙과 실제 수행 가능한 일정이 있을 때만 계산한다.
3. **장비와 내실을 나란히 검토한다.** `stat`·`item-equipment` 및 필요한 `set-effect`·`symbol-equipment`·`vmatrix`·`hexamatrix`·`hexamatrix-stat`·`user/union*`를 선택한다. 목표에 무관한 모든 API를 수집하지 않는다.
4. **교체 묶음을 비교한다.** 한 부위 교체, 세트 변경 묶음, 코어 투자, 누적 성장/연습을 비교한다. 세트효과 손실·잠재·주문서·특수 옵션·해방 전후 무기의 사용기간·판매 비용을 반영한다. 개별 증가율을 단순 합산해 세트 교체 효과로 쓰지 않는다.
5. **예산과 실행 순서를 정한다.** 지금 살 매물, 이벤트 때 강화할 후보, 누적해야 할 재료를 구분한다. 이벤트 일정은 공식 공지로 확인하고 미발표 이벤트를 확정 일정으로 잡지 않는다. 대기 중 놓치는 콘텐츠와 사용자 취향도 고려한다.

가능한 수치 비교는 `calculate_final_damage_gain`과 `calculate_upgrade_expectation`을 호출한다. 입력이 같은 전투 조건인지 확인하며 쿨감·시드링·스킬 배율·포스 변화는 단순 데미지 비율 모델의 적용 범위를 먼저 검토한다. HEXA 강화 순서는 직업·현재 코어·스킬 점유율·재료 보유량에 따라 검토하고, 오래된 풀강 표의 순서를 모든 중급에게 복사하지 않는다.

## 시간을 포함한 성장 효율

해당 사용자가 실제로 할 수 있는 주간 보스와 사냥량을 기준으로 자원 수급을 잡는다. 원킬·사냥 편의·드메 투자가 필요한 질문이면 [playstyle.md](playstyle.md)를 적용한다. 고정 보상과 확률 드롭을 구분하고, 좋은 드롭을 얻는다는 가정으로 예산을 채우지 않는다.

부캐 확장은 초기 세팅비·추가 코어/심볼·주간 소요시간·본캐 투자 지연을 함께 계산한다. 보스 수익 숫자만으로 여러 주보 캐릭터를 기본 추천하지 않는다. 기간제 육성 보상이 끝난 뒤에도 유지 가능한지 확인한다.

## 답변과 보류 조건

주된 병목을 먼저 설명하고, 의미 있는 대안이 있으면 `선택 / 예상 효과 / 총비용 / 시간·위험 / 언제 선택할지`로 비교한다. 확정 수치와 가정은 구분한다. 가격·복구비·교체 후 스탯 중 하나가 결론을 바꾸면 순위를 조건부로 남긴다.

해당 목표의 기본 요건이 갖춰지고 작은 투자 차이나 운영 최적화가 주요 문제가 되면 `advanced`로 전환한다. 새 부캐·새 보스·복귀 후에는 해당 분야에 필요한 기본 설명을 다시 제공할 수 있다.
