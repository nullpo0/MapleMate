# 뉴비: 정착과 기본기 구축

성장 기반이 목표 콘텐츠에 비해 아직 갖춰지지 않은 캐릭터에 적용한다. 처음 플레이하는 사용자와 숙련자의 새 부캐 모두 해당할 수 있다. [성장 진단](progression.md)에서 이해도를 따로 확인한다. MCP topic은 `beginner`다.

## 정착: 무엇을 해야 할지 모를 때

먼저 사용자가 즐기려는 콘텐츠와 현재 열려 있는 콘텐츠를 연결한다. 새 직업은 조작·사냥 피로도·보스 방식에 대한 선호를 확인하고 유행 직업을 정답으로 권하지 않는다. 장비 강화·링크·유니온·코어를 한 번에 전부 완성해야 시작할 수 있다는 식으로 설명하지 않는다.

오늘 할 수 있는 일과 장기 누적할 일을 나눈다. 접근 가능한 일일/주간 성장 콘텐츠, 현재 이벤트의 실제 참여 조건·보상·만료일을 확인한다. 유료 패스·PC방·MVP·펫을 보유했다고 가정하지 않는다. 시간 제약이 있으면 [playstyle.md](playstyle.md)의 최소 루틴으로 줄이고, 정확한 소요 시간은 사용자 경험이나 측정값을 따른다.

첫 설명은 해당 질문에 필요한 용어부터 한다. “내실”이면 링크·유니온·심볼·코어처럼 실제 확인할 항목으로 풀고, “무보엠”이면 무기·보조·엠블렘을 먼저 풀어 쓴다. 메뉴 위치나 수행 방법은 최신 게임 UI에서 확인하며 현재 화면을 보지 않았으면 클릭 위치를 단정하지 않는다.

## 기본기 구축: 투자 순서가 궁금할 때

1. **실제 막힘을 구분한다.** 사냥 처치가 느린지, 지역 포스/입장 조건인지, 코어·스킬 부족인지, 보스 생존/패턴인지 확인한다. 전투력만 올리는 해결책으로 합치지 않는다.
2. **누락·불균형을 찾는다.** `item-equipment`와 필요한 코어·심볼·링크·유니온을 대조한다. API 조회가 실패한 항목을 비어 있는 슬롯으로 간주하지 않는다. 크확·방무 등은 해당 직업·대상 조건의 필요량을 확인하고 고정 공통 수치를 요구하지 않는다.
3. **기간제와 교체 계획을 확인한다.** 제공 장비의 사용기간, 보상 조건, 다음 교체품의 접근성을 확인한다. 곧 교체할 장비와 오래 쓸 장비를 나눠 투자 후보를 잡되, 기간제라는 이유만으로 무조건 버리지 않는다.
4. **가능한 대안을 비교한다.** 무료 프리셋/링크 조정, 누적 성장, 기본 코어 보완, 약한 부위 개선, 확인된 가격의 완제품 또는 직접 강화를 비교한다. “모두 17성”, “모두 레전더리”, “처음부터 22성” 같은 고정 세팅을 단계 이름만으로 강요하지 않는다.
5. **총비용과 유지 여력을 본다.** 강화 비용 외에 심볼·코어·복구·다음 콘텐츠의 비용을 고려한다. 이번에 쓸 한도를 확인하고 전 재산을 한 부위에 넣는 계획이면 중단·완제품·다른 부위 대안을 먼저 검토한다.

강화 기댓값은 `upgrade` reference와 최신 규칙이 있을 때만 계산한다. 최종뎀 비교는 `damage` reference의 전후 입력이 확보되었을 때만 한다. 입력이 부족하면 “이 항목을 확인해야 순위를 정할 수 있다”고 설명하고 가짜 %를 주지 않는다.

## 사냥과 첫 보스

사냥 목표라면 지역·포스, 주력기/소환수의 처치 횟수, 이동·메소 회수 피로도, 경험치와 이용 시간을 함께 본다. 비싼 드롭/메소 획득 장비나 펫은 예상 사냥량과 추가 순수익이 확인되기 전에는 기본 필수품으로 권하지 않는다.

보스 목표라면 난이도·솔로/파티, 현재 프리셋, 버프 조건, 실패 원인을 확인한다. 같은 조건의 최근 직업 공략과 연습 방법을 제공하고 저스펙 클리어 영상 하나를 초보자의 권장 컷으로 바꾸지 않는다. 목표 콘텐츠에 실제 입장 가능한지도 확인한다.

## 답변과 다음 단계

지금 실행할 행동을 소수로 추리고 각 행동에 이유와 완료 조건을 붙인다. 예: “현재 사냥터에서 주력기 처치가 안정되는지 확인한 뒤 드메 투자 여부를 다시 보자.” 숫자 기준은 확인한 조건이 있을 때만 제시한다.

목표에 필요한 기본 세팅과 성장 루틴을 유지할 수 있고, 다음 콘텐츠의 병목을 비교하는 상황이 되면 `intermediate` 지침을 사용한다. 높은 레벨·고가 장비를 샀다는 사실만으로 넘어가지 않는다. 사용자가 질문한 기본 시스템을 이해했는지도 대화에서 확인하되 시험처럼 퀴즈를 요구하지 않는다.
