# 강화 근거와 계산 규약

대상: 한국 메이플스토리(KMS). 확인일: 2026-10-09. 아래 링크는 검색의 시작점이며 고정된 최신 규칙표가 아니다.

- 공식 게임 가이드: https://maplestory.nexon.com/Guide/N23GameInformation
- 공식 업데이트: https://maplestory.nexon.com/News/Update
- 강화 개편 공지: https://maplestory.nexon.com/news/update/799
- Nexon API: https://openapi.nexon.com/ko/game/maplestory/

공식 가이드와 업데이트의 내용이 다르면 적용일·수정일을 확인한다. 과거 스타캐치 또는 파괴 복구 규칙을 사용하는 계산기를 현재 규칙에 그대로 적용하지 않는다. 테섭 공지는 본섭 적용 여부를 별도로 확인한다.

## 용어와 입력

- 스타포스: 별 단계에 따른 장비 강화. 현재 단계, 원래 착용 레벨, 장비 유형, 해당 강화의 제한 조건을 확인한다.
- 잠재옵션/에디셔널 잠재옵션/추가옵션은 서로 다른 정보다. 툴팁 숫자를 한 종류로 합치지 않는다.
- 기댓값: 명시한 정책을 반복했을 때의 평균 비용. 유저가 한 번 시도할 때 필요한 확정 예산이나 예산 내 성공 확률과 다르다.
- 파괴 시 흔적 복구, 대체 장비 가격과 이벤트 할인은 선택한 정책에 따라 비용에 포함한다. 시세는 월드와 확인 시각을 기록한다.

## calculate_upgrade_expectation

각 비목표 상태는 `id`, `attempt_cost`, `transitions`를 갖는다. 전이는 `next_state`, `probability`(합계 1), 선택적인 `extra_cost`, `destruction`을 갖는다. 목표는 별도의 흡수 상태이며 `states` 목록에 넣지 않는다.

전이의 `extra_cost`는 해당 결과가 발생했을 때만 지불하는 복구/재구매 비용이다. 이미 `attempt_cost`에 반영한 비용을 중복해서 더하지 않는다. 실패 횟수나 보호 상태가 다음 확률에 영향을 준다면 `17_fail0`, `17_fail1`처럼 상태를 분리한다. 파괴 이후 상태는 검색으로 확인한 복구 정책에 맞춰 지정한다.

함께 전달하는 `source_urls`, `rules_as_of`, `assumptions`에는 사용한 근거, 적용일, 할인·복구·대체 장비 비용 가정을 명시한다. 서버는 입력 규칙의 최신성을 확인하지 않으며, 이 도구에는 고정된 스타포스 확률표가 없다. 입력을 완성할 근거가 없으면 수치 결론을 보류한다.
